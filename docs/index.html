Noricum

Autonomous C-to-Rust migration agent — 0 unsafe blocks, verified by differential testing.

Noricum translates C source code to safe, idiomatic Rust using LLM agents, then proves behavioral equivalence by compiling both versions and comparing outputs byte-by-byte. If they differ, the LLM fixes it automatically.

How It Works

  1. Analyze — Classify difficulty, identify patterns (malloc, goto, unions)
  2. Translate — LLM generates idiomatic Rust with RAG pattern context
  3. Verify — Compile both C and Rust, compare outputs byte-by-byte
  4. Repair — If outputs differ, LLM auto-fixes (up to 5 iterations)

Quick Start

git clone https://github.com/JuanMarchetto/noricum
cd noricum && cargo build --release

# Set your API key
export ANTHROPIC_API_KEY=sk-ant-...

# Migrate a C file with full verification
noricum migrate path/to/file.c --diff-test --report report.html
